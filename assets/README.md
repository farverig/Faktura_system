# Logo til Farverig

Læg logoet i denne mappe og navngiv det **logo.png**.

På GitHub: Åbn `assets` → **Add file** → **Upload files** → vælg logoet → **Commit changes**.

Når GitHub Pages har opdateret hjemmesiden, vises logoet automatisk øverst og på udskrevne fakturaer. Brug helst en PNG med transparent baggrund. Alternativt kan du bruge `logo.svg` ved at ændre filstien i `index.html` og `app.js`.

Bemærk: Logoet er offentligt tilgængeligt på GitHub Pages.
